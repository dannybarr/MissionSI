MISSION — PRODUCT BRIEF (public)
amission.si

WHAT IT IS
A personal AI memory you own. It is stored encrypted on a physical device you carry.
AI agents can use it through an MCP connector, with per-agent permissions.
Pull the device out and connector access stops.

STATUS TODAY
- Software v1 is a plan being validated, not a released product. Planned design: an encrypted
  USB-C stick holds the memory; a local helper detects it, decrypts it, runs the MCP connector,
  and can optionally use Ollama for local AI. Memory would be usable only while connected.
- The access demo on amission.si is a browser simulation, not working software.
- Local MCP support is strongest in Claude Desktop. Support in other agents varies.
- There is no one-click memory import from AI providers. Imports start from each provider's data export.

HONEST LIMITS
- Agents see whatever memory is shared during a session. Remote providers may retain it.
- Unplugging stops future access. It does not erase or recall anything already shared.
- Safe claims: minimal sharing, temporary chats, and a local audit log. Not "zero exposure".
- A standard USB stick cannot be locked to memory-only use. That needs custom hardware.

PLANNED (NOT BUILT)
- Custom card: graphite, credit-card sized, about 4.4 mm, inward-cut edges, with a built-in
  USB-C connector so it plugs straight into a laptop. Earth mark, Mission wordmark, your initials.
  A small status light shows when an agent has access.
- Optional modules being explored: Bluetooth, GPS, push-to-talk mic, secure element (NXP SE050),
  NFC, haptics. 32-128 GB storage.
- Signals (opt-in): location, speech transcribed locally, a chief-of-staff feed.
- Phone app as Bluetooth bridge. Payments later: open banking first.

PRICE
Founding target for the custom card: GBP 249. Not taking orders, deposits or reservations.
